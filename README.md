# OJK Coffee Shop — Design Thinking Website

Website statis HTML, CSS, dan JavaScript. Tidak memerlukan instalasi framework atau database.

## Menjalankan di komputer
1. Ekstrak folder project.
2. Buka `index.html` di browser, atau gunakan ekstensi Live Server di VS Code.

## Deploy ke Vercel
**Cara paling mudah (GitHub):**
1. Buat repository baru di GitHub.
2. Upload seluruh isi folder project ini (index.html, style.css, script.js, dan folder assets).
3. Login ke https://vercel.com lalu pilih **Add New → Project**.
4. Import repository GitHub tersebut.
5. Pada pengaturan build, pilih **Other** / Framework Preset: Other.
6. Biarkan Build Command dan Output Directory kosong (atau gunakan konfigurasi static sesuai tampilan Vercel), lalu klik **Deploy**.

Alternatif: install Vercel CLI dan jalankan `vercel` dari folder project.

## Catatan akademik
Bagian kuesioner di website berisi DATA SIMULASI 20 responden untuk contoh tampilan dan perhitungan. Ganti narasi observasi dan seluruh angka dengan hasil penelitian/kuesioner asli sebelum dikumpulkan. Jangan menyajikan data simulasi sebagai data lapangan.
